TRADING SYSTEM — PHONE APP

This is a small installable web app. It is designed for a phone browser and keeps checklist progress and notes in that browser on that device.

TO TRY IT:
1. Extract the ZIP.
2. Open index.html in a browser to test the checklist. (Install/offline features require HTTPS hosting.)
3. To install it like an app, host the files on an HTTPS site, such as GitHub Pages.
4. Open the hosted address in Chrome on Android, use the browser menu, then choose "Install app" or "Add to Home screen".

IMPORTANT:
- Data is stored locally in the browser. It does not automatically sync between devices.
- Use Export checklist data to make a backup.
- This is a checklist and notes tool, not a broker connection, signal generator, or automated trading bot.
